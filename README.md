# ✨ Quantora — AI for Finance

## 📌 Overview

Quantora is a premium finance SaaS landing page concept designed to showcase an AI-powered financial research copilot. 

It combines modern web design with editorial typography, custom illustrations, scroll-driven animations, and interactive experiences to create a distinctive digital presence.

## 📝 Description

Quantora presents an AI-powered financial research platform built to help investment professionals simplify research, explore opportunities, and make informed decisions.

The website features a carefully crafted visual identity with warm orange tones, soft neutral backgrounds, deep navy accents, and elegant serif typography.

Designed with a focus on visual storytelling, the experience combines scroll-triggered card animations, layered floating elements, interactive accordions, smooth transitions, and responsive layouts to create an engaging browsing experience.

---

## 🚀 Features

- 📱 **Fully Responsive Design** — Adaptable layouts optimized for desktop, tablet, and mobile devices.
- 🎴 **Scroll-Driven Card Stacking** — Layered cards that animate, overlap, rotate, and transition as users scroll through the experience.
- 🔄 **Interactive Card Transitions** — Dynamic card reveals with smooth position, rotation, and stacking effects.
- ✨ **Scroll-Based Storytelling** — Progressive content reveals that guide users through different sections of the landing page.
- 🪄 **Floating Card Interactions** — Animated floating research cards with depth, layered shadows, and smooth movement.
- 🧭 **Smooth Section Navigation** — Seamless navigation with anchor scrolling and responsive navigation elements.
- 🎯 **Interactive Accordion** — Expandable research benefits with active states and smooth content transitions.
- 🖱️ **Micro-interactions & Hover Effects** — Subtle animations across buttons, cards, links, and interactive elements.
- 🎨 **Editorial Visual Identity** — Elegant serif typography, warm orange accents, navy backgrounds, and balanced neutral colors.
- 🖼️ **Custom Illustrated Visuals** — Consistent finance-inspired illustrations that strengthen the website's visual storytelling.
- 📐 **Responsive Component Layouts** — Carefully adjusted spacing, alignment, typography, and image proportions across screen sizes.
- ⚡ **Performance & Accessibility** — Semantic structure, optimized assets, and consideration for reduced-motion preferences.

## 📂 Website Sections

- **Navbar** — Minimal navigation with brand identity, section links, and a Request Demo CTA.
- **Hero** — Bold introductory headline, supporting description, primary CTA, and illustrated finance research visual.
- **Purpose-Built for Financial Research** — Highlights proprietary data, deep financial research, and rapid insights.
- **Finance Research Copilot** — Interactive accordion showcasing the platform's research capabilities.
- **Financial Data & Capabilities** — Feature cards highlighting financial knowledge, enterprise-grade security, and AI-powered research.
- **Built for Every Analyst** — Showcases industry-specific use cases, including private equity, investment banking, credit, hedge funds, and venture capital.
- **What You Can Expect** — Scroll-driven storytelling section featuring overlapping, rotating, and animated floating research cards.
- **Quantora Academy** — Educational resources, webinars, whitepapers, and financial insights.
- **Final CTA** — Visually engaging call-to-action section encouraging users to get started.
- **Footer** — Brand-focused footer with company information, navigation links, and social connections.

## 🛠️ Tech Stack

- **Next.js** — React framework for building the application.
- **React** — Component-based UI development.
- **JavaScript** — Application logic and interactive functionality.
- **CSS / Styled JSX** — Custom styling, responsive layouts, and animations.
- **Framer Motion** — Scroll-based animations, card transitions, and motion effects.
- **Lucide React** — Lightweight icons for interface elements.
  
---

## 🎨 Design Approach

- **Visual Style:** Modern editorial, minimal, and premium SaaS.
- **Typography:** Elegant serif display typography paired with clean sans-serif body text.
- **Color Palette:** Warm orange, soft cream, pale blue, and deep navy.
- **Layout:** Spacious compositions, balanced grids, rounded cards, and layered elements.
